Problem Statement

外貿書信的三大痛點

01

費時費工

每封英文書信需查閱術語、牙規、認證，翻譯與校對耗時，業務量一大就延遲回覆。

02

術語易錯

水五金規格（NPT/BSPT、CW617N、NSF/ANSI 372…）用詞稍有偏差，易造成國際誤解。

03

風險承諾

用詞不當可能誤導「零漏水」等過度承諾，釀成商務與法律責任。

目標：讓業務人員在「分鐘級」內產出專業英文書信，並自動判讀案件急迫性。

Solution Overview

兩大工具，一條龍

A

AquaFlow BizMail

純前端 Web 工具：輸入中文草稿 → 選擇收件人關係與語氣 → 生成四大輸出（主旨建議、正文翻譯、商務風險提醒、閱讀體感）。

純前端可離線支援 LLM API
B

案件自動分類

導入 laya-burger 決策模型，讀取案件 CSV，自動分類案件類型、評估急迫性（P）與衝突程度（0–3）。
